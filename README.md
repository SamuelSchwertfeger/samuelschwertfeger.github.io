# samuelschwertfeger.github.io

Personal academic website of Samuel Schwertfeger, built with SvelteKit as a static site. Live at https://samuelschwertfeger.github.io
Run `npm run dev` to develop and `npm run build` to produce the static site in `build/`.
Edit content in `src/lib/data` (YAML files for CV, research, projects, publications).
